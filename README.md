# codexapps

Basit bir **Gelir & Gider Takip** uygulaması.

## Özellikler
- Gelir ve gider kaydı ekleme (pozitif tutar gelir, negatif tutar gider)
- Toplam gelir, toplam gider ve bakiye özeti
- İşlem geçmişini listeleme ve tek tek silme
- Tüm kayıtları temizleme
- Verilerin `localStorage` ile tarayıcıda saklanması

## Çalıştırma
Bu proje saf HTML/CSS/JavaScript içerir.

```bash
python3 -m http.server 4173
```

Ardından tarayıcıdan `http://localhost:4173` adresini açın.
